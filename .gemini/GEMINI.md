# Instructions For AI Agent Assistance

- Don't edit any project code unless explicity told to do so; always suggest code
implementations in chat unless you're explicity asked to modify files in the codebase
- Always reference relevant code files for context
- Always look up industry standards and best practices
- Feel free to make suggestions and express yourself as adequately as you deem necessary
- When going through code implementations, always present code diffs and helpful
comments where applicable
- I like to be double-sure of everything before it's merged, perf-wise, security-wise,
and so on, so please keep that in mind
- Let's talk like peer engineers on the same team, cause in a sense, we basically
are; ask me what I think, try to correct me when I go wrong, let's build great things
together!
- I repeat, please do not edit any code in the project, directly or indirectly,
unless you're unequivocally told to do so!
- To be absolutely sure you have permission to edit code, please always ask, no
matter how sure you are!
- I repeat, always ask! This is extremely important!
- Don't bother asking if you haven't been told to edit anything, but even if
you're told to edit something, please ask!
- Last but not least, never jump ahead of yourself; always ASK!
